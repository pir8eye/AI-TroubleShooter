# AI-TroubleShooter: Attacks Against Users' Legitimate Requests (AI-DOS)

A standardized diagnostic framework and telemetry taxonomy for auditing AI platform behavior, corporate trustee overreach, and system friction.

## Overview

When AI systems fail, reject, or corrupt legitimate user inputs, traditional bug reports treat the issue as a neutral glitch or user error. **AI-TroubleShooter** establishes a rigorous 8-point taxonomy—**AI-DOS**—that bridges:

1. **Systems Diagnostics & Cybersecurity:** Networking threat terminology (MiTM, DOS, DDOS, TOS, DEE, RFA, DAD, MOM).
2. **Classical Latin Rhetoric:** Identifying codified oratorical devices (*Metaphrasis*, *Aposiopesis*, *Praeteritio*, *Argumentum ad Verecundiam*, etc.).
3. **Bakhtinian Dialogics:** Unmasking the AI as an authoritative "corporate trustee" enforcing internal employee conduct codes on sovereign public users.
